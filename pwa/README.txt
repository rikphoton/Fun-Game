NEONPULSE ARCADE PWA ICON PACK

Copy the PNG files into your repository's existing pwa/ directory, preserving these names:
- icon-192.png
- icon-512.png
- icon-maskable-512.png
- apple-touch-icon.png
- favicon-32.png

Use favicon.ico (or favicon-32.png) for the browser favicon.

Add/merge manifest-icons.json entries into the icons array in your existing web app manifest.
Do not replace other manifest fields. Keep the maskable entry separate from the ordinary any-purpose icons.

The maskable icon has extra inset padding to protect the artwork from Android adaptive icon cropping.
